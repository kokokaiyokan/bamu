BOOTH Asset Management Utility BLM連携

Unityを開くとBOOTH Asset Management Utilityが受信を自動開始します。Managerの「設定」→「接続設定…」→「Chrome（BOOTH）」→「初期設定」から接続キーをコピーして入力してください。

ログインはChromeのBOOTHページで行います。パスワードやCookieをこの拡張へ入力する必要はありません。商品はUnity Managerの左一覧、取得ファイルは商品詳細で選択できます。Unityを開いている間に同期します。取得はBLMが行います。BLMを起動しておいてください。Chromeでアプリ起動の確認が出た場合は対応してください。
