# BOOTH Asset Management Utility

BOOTH Library Managerの商品とUnity内のフォルダ・ファイルを結び付ける非公式のEditor拡張です。for VRChat。バージョン0.1.0。

省略名はBAMU、内部識別子は`bamu`です。BOOTH・pixiv・VRChatの公式ツールではありません。Windows / Unity 2022.3 / BLM 0.5.0（スキーマ20261005）向けです。

## 導入・起動

Package Managerの「Add package from disk...」でこのフォルダの`package.json`を選びます。配布用の`bamu-0.1.0.tgz`は「Add package from tarball...」で導入できます。

`Window > BOOTH Asset Management Utility`を開いてください。VCCプロジェクトでも同じ手順です。VCCのリポジトリ配信は未対応です。

## 商品一覧と検索

左側は商品ごとに1カードです。画像、商品名、作者名と、Assetリンク／BLM保存の✓・×を表示します。カード全体をクリックして選択でき、カードへProjectのアセットをドラッグして手動リンクできます。

商品検索は商品名・作者名・設定済みタグが対象です。候補だけのタグは含みません。表示対象はすべて／BLM保存済み／Assetリンク済み。並び順は登録順／商品名／ショップ名／商品IDと↑↓で切り替え、表示数は50／100／200件です。登録順はBLMの登録順で、未登録の商品は後ろに表示します。

## 上部メニュー

「設定」には次の操作があります。

- 接続設定…：BLMの実行ファイル・DB・保存先と、Chrome連携を別ウィンドウで設定。
- 辞書設定…：タグの採用方法・採用タグ・表記ゆれを別ウィンドウで編集。
- BOOTH → BOOTHを確認：Chromeへ商品一覧の確認を要求。ファイル取得は開始しません。
- BOOTH → BLM未登録を一括ダウンロード：その時点の未登録VRChat対象商品を手動で一括取得。
- アセット → 既存アセットを探す（全商品）：保存済み配布物を使ってProject内を照合。
- BLM連携再読み込み：BLMのDB・選択商品の保存ファイル一覧を読み直す。
- Assetリンク情報再読み込み：Projectのリンク台帳とリンク先の表示・prefab候補を更新。

設定横の「逆引き検索」はProjectの選択から関連商品を表示します。商品を選択するか「商品詳細へ戻る」で詳細へ戻れます。

## リンクと導入

商品詳細の「Project内格納ディレクトリ」に導入元をフォルダ単位で表示します。実際のリンクはファイルごとのGUIDで保持し、未導入の子ファイルを一括で所有扱いにはしません。表示フォルダの変更にも対応します。

Assetリンクがない商品には「既存アセットから探す」「BLM保存ファイルから導入」を表示し、後者はBLM未保存時には無効になります。既存アセットの自動照合にはBLMの配布ファイルが必要です。配布物がない場合は手動リンクを使えます。

この画面からunitypackageを導入すると、Unityが取り込んだ項目を自動でリンクします。既存アセットの照合は候補の確認後にリンクし、走査だけでは変更しません。導入元・改変用コピー・参考リンクを区別します。

## タグと商品画像

自由タグと採用辞書は全プロジェクト共通です。自動採用／候補表示のみ／辞書参照なしを選べます。BOOTHの商品タグは辞書内の語と明示した表記ゆれだけを採用対象にし、サブカテゴリは候補へ表示します。辞書設定は保存ボタンで適用します。

BLMのローカル画像を優先し、URL画像はユーザーの`%LOCALAPPDATA%/bamu/thumbnails`へ保存します。保存済み画像は再起動やプロジェクト切り替えでも再利用し、旧名称の画像も読み取り時に引き継ぎます。外部取得は接続設定から切り替えられます。

## prefab

「使用するprefab」は導入元を優先して代表1個を表示します。default等を含む名前、浅い階層、パス順を補助的に使う選択で、色や体型の意味は推測しません。「表示するprefabを追加・変更」から手動で選択・追加できます。選択はProjectの台帳へGUIDで保存し、移動に追従します。「外す」は表示から外す操作で、ファイルや既存リンクは削除しません。

Hierarchyのアバターのルートを配置先へ指定し、「アバターに配置」で子として追加します。衣装側のMA等の設定を維持し、Ctrl+Zに対応します。ボーンの付け替え・体型変換・シーンの自動保存は行いません。

変換ツール連携は任意モジュールです。登録されたモジュールに応じて変換ボタン・処理状況・待機解除を表示します。モジュールがない場合、prefab表示・選択・配置・手動リンクは引き続き利用できます。標準配布物にはローカルモジュールを含めません。[モジュールAPI](Documentation~/prefab-converter-modules.md)を参照してください。

## BOOTH・BLM連携

Unityが起動時に受信を開始し、複数プロジェクトでは1つが受信役になります。ChromeでBOOTHへログインし、BLMを起動してください。初期設定は「設定」→「接続設定…」→「Chrome（BOOTH）」にあります。[詳しい手順](Documentation~/booth-sync.md)を参照してください。

取得は公式BLMリンクを使い、BLMへの登録・展開はBLMが行います。登録済みの商品は新版やファイル不足があっても一括取得の対象外です。自動更新取得はありません。Unityをすべて閉じている間は連携の受信・保存確認を休止します。

## 保存先・制約

- Project台帳：`ProjectSettings/bamu.json`。
- インポート待機：`UserSettings/bamu/`。
- 再生成可能なキャッシュ：`Library/bamu/`。
- 接続情報、連携台帳、タグ、辞書、画像：`%LOCALAPPDATA%/bamu/`。受信データ保存先に独自設定がある場合は維持します。

BLMのDBへは書き込みません。旧データの移行と新旧ロックの確認に対応し、旧ファイルは保持します。名称変更後は利用する全Unityプロジェクトを更新してください。

コードのコアテストとUnity実DLLでのコンパイルを実施しています。実Editorでの画面・Undo・名称変更後のレイアウト復帰は別途確認が必要です。
